# Atividade avaliativa 2 :


* Projete o banco de dados de infrações dos DETRANs, insira 5 linhas em todas as tabelas e faça as consultas solicitadas abaixo. Para a avaliação desse exercício, deve ser enviado para o professor:

* Diagrama de Entidade e Relacionamento (Modelo Conceitual);
* Modelo Relacional (Modelo Lógico);
* SQL do Schema do Banco (Modelo Físico);
* SQL dos Inserts;
* Prints do Banco de Dados criado no PostgreSQL (print da relação das tabelas criadas e print de algumas tabelas com seus respectivos dados);
* Faça as seguintes consultas ao banco de dados (prints que mostram a consulta SQL e o resultado):
* Mostre o nome do proprietário e a quantidade de veículos que ele possui, exibindo apenas os proprietários que têm mais de um veículo registrado;
* Liste todos os proprietários cujo nome começa com a letra "M" e que possuem pelo menos um veículo cadastrado no sistema. A consulta deve exibir o nome do proprietário, o CPF e o número da placa de cada veículo;
* Mostre o nome do tipo de infração e o valor total cobrado pelas ocorrências desse tipo, agrupando os resultados por tipo de infração;
* Exiba a placa do veículo, a velocidade aferida, a velocidade permitida e o local da infração, somente para os casos em que a velocidade aferida for maior que a permitida;
* Liste a placa do veículo, o nome do proprietário, o tipo de infração, a data e hora da ocorrência e a UF onde ela ocorreu, somente para o "DF".
* Obs: A descrição dos requisitos do banco de dados está no arquivo em anexo.
